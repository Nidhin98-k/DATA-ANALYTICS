# Urban Intelligence Dashboard

## Overview

Urban Intelligence Dashboard is a Power BI project created to analyze urban traffic and mobility data across different cities.

The dashboard provides an interactive view of traffic conditions, travel-time performance, city comparisons, time-based traffic patterns, and detailed traffic records.

## Tools Used

- Power BI
- DAX
- Power Query
- Data Modeling

## Dashboard Pages

### 1. Overview
Provides a high-level summary of urban traffic and mobility performance.

- Live Traffic Index
- Live Travel Time
- Historical Travel Time
- Time Delta
- Delay %
- Peak Hour
- Monthly Traffic
- City Performance
- Interactive City Map

### 2. Traffic Intelligence
Focuses on traffic conditions and congestion patterns.

- Traffic Index
- Peak Traffic Index
- Traffic Range
- Peak Hour
- Daily Traffic Trend
- Hourly Traffic Profile
- Peak vs Off-Peak Traffic
- Live vs Historical Travel Time

### 3. Mobility Intelligence
Analyzes travel-time performance and mobility efficiency.

- Live Travel Time
- Historical Travel Time
- Time Delta
- Delay %
- Mobility Status
- Delay % by City
- Travel-Time Difference by City

### 4. City Comparison
Compares traffic and mobility performance across different cities.

Cities included:

- Cairo
- Doha
- Dubai
- Kuwait
- Riyadh

This page includes:

- Traffic Index by City
- Live Travel Time by City
- City Performance Matrix
- City Traffic Ranking
- Travel-Time Change %
- City Traffic Spread

### 5. Time Intelligence
Analyzes traffic patterns across different time periods.

- Peak Traffic Hour
- Peak Traffic Index
- Off-Peak Traffic Index
- Peak vs Off-Peak %
- Hourly Traffic Pattern
- Monthly Traffic Pattern
- Traffic by Day of Week
- Peak vs Off-Peak Traffic by City

### 6. Advanced Analytics
Provides deeper analysis of traffic patterns and variability.

- Average Traffic
- Traffic Variability
- Average Delay
- Peak Traffic
- Traffic Variability by City
- High-Traffic Observations by City
- Hour-level traffic analysis

### 7. Detail Center
Provides record-level traffic and mobility information.

Users can filter the data by:

- Date
- City
- Hour

The detail table includes:

- Traffic Index
- Live Travel Time
- Historical Travel Time
- Travel-Time Difference
- Travel-Time Change %
- Traffic Status

## Key Features

- Interactive page navigation
- City filtering
- Date and time filtering
- Reset controls
- Interactive map
- KPI cards
- Traffic trend analysis
- City comparison
- Time-based analysis
- Detailed data exploration
- Dark-themed command center design

## Project Objective

The main objective of this project is to use Power BI to transform urban traffic and mobility data into an interactive dashboard that makes it easier to understand traffic conditions, compare cities, identify patterns, and explore detailed observations.
