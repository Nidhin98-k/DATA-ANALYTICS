# HR Analytics Dashboard

## Overview

HR Analytics Dashboard is a Power BI project created to analyze employee data, workforce distribution, and employee attrition.

The dashboard provides an interactive view of employee demographics, department-wise workforce, salary levels, job satisfaction, gender distribution, and attrition patterns.

## Tools Used

- Power BI
- DAX
- Power Query
- Data Modeling

## Dashboard Analysis

### Employee Overview

The dashboard provides key HR metrics including:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate %
- Average Age
- Average Experience

### Department Analysis

The dashboard provides department-level analysis of:

- Employee distribution
- Attrition by department
- Department-wise employee count

Departments included:

- Administration
- Finance
- Human Resources
- IT
- Marketing
- Operations
- Sales

### Attrition Analysis

The dashboard analyzes employee attrition based on different factors:

- Attrition by Department
- Attrition by Salary Slab
- Attrition by Gender
- Attrition by Job Role and Satisfaction
- Attrition Trend by Experience

### Employee Demographics

Employee distribution can be analyzed based on:

- Age Group
- Gender
- Department
- Experience

Age groups included:

- 18–25
- 26–35
- 36–45
- 46–55
- 55+

### Interactive Filters

The dashboard includes interactive filters for:

- Age Group
- Department

These filters allow users to explore the HR data based on different employee segments.

## Key Features

- Interactive HR dashboard
- Employee KPI cards
- Attrition analysis
- Department-wise analysis
- Salary slab analysis
- Job satisfaction analysis
- Age group analysis
- Gender analysis
- Experience-based analysis
- Interactive filtering
- Data visualization

## Project Objective

The main objective of this project is to use Power BI to analyze employee data and understand workforce distribution and attrition patterns.

The dashboard helps explore factors such as department, salary level, age, gender, experience, and job satisfaction that can be used for HR analysis.
