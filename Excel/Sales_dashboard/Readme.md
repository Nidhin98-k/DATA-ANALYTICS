# Sales Distribution Dashboard

An interactive **Microsoft Excel Sales Distribution Dashboard** designed to analyze sales performance across regions, countries, products, customers, and time periods.

## 🎯 Project Objective

The objective of this project is to transform sales data into an interactive dashboard that provides a clear overview of sales performance and helps identify important business trends.

## 📌 Key Features

- **Total Sales KPI**
- **Top 3 Customers**
- **Sales by Region**
- **Sales by Country**
- **Top 10 Products**
- **Monthly Target vs Actual Sales**
- **Weekly Sales Analysis**
- **Interactive Month Filter**
- **Interactive Region Filter**

## 📈 Dashboard Insights

The dashboard provides analysis of:

- Overall sales performance
- Regional sales distribution
- Monthly sales trends
- Weekly sales patterns
- Top-performing customers
- Top-performing products
- Country-wise sales distribution
- Target vs actual monthly performance
