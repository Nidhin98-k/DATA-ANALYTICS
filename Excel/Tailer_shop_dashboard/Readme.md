# Tailor Shop Performance Dashboard

An interactive **Microsoft Excel Tailor Shop Performance Dashboard** designed to analyze orders, garment types, materials, costs, processing time, and monthly performance.

## 🎯 Project Objective

The objective of this project is to analyze tailor shop operations and present key performance metrics through an interactive Excel dashboard.

The dashboard provides an overview of order volume, garment demand, costs, processing time, order status, and monthly trends.

## 📌 Key Features

- **Total Orders**
- **Total Cost**
- **Average Cost per Order**
- **Highest Cost Garment Type**
- **Most Ordered Garment Type**
- **Average Processing Time**
- **Order Status Distribution**
- **Cost by Garment Type**
- **Orders by Garment Type**
- **Monthly Cost Trend**
- **Average Cost by Material**
- **Average Cost by Garment Type**
- **Monthly Order Trend**
- **Material Distribution**
- **Average Processing Days by Garment Type**
- **Interactive Order Status Filter**
- **Garment Type Filter**
- **Month Filter**
- **Material Filter**

## 📈 Analysis Areas

The dashboard provides insights into:

- Overall order volume
- Order status distribution
- Garment demand
- Garment-wise costs
- Material-wise costs
- Material distribution
- Monthly cost trends
- Monthly order trends
- Average processing time
- Processing time by garment type
